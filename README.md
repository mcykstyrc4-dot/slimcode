# Slim Code Lab — одностраничный лендинг

Редизайн сайта сети салонов аппаратной коррекции фигуры «Slim Code Lab»
(LPG-массаж, RSL-скульптурирование, миостимуляция, прессомассаж, кавитация).

Лендинг — один файл **`index.html`**: HTML + CSS + JS, без сборки и фреймворков.
Открывается двойным кликом, заливается на любой хостинг как статика.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | лендинг целиком: разметка, стили и скрипты в одном файле |
| `privacy.html` | политика конфиденциальности (шаблон) |
| `terms.html` | пользовательское соглашение (шаблон) |
| `consent.html` | согласие на обработку персональных данных (шаблон) |
| `legal.css` | общие стили трёх юридических страниц |
| `robots.txt` | правила обхода + ссылка на карту сайта |
| `sitemap.xml` | карта сайта |

Юридические страницы намеренно закрыты от индексации
(`<meta name="robots" content="noindex, follow">`), пока в них шаблонный текст.
После заполнения реквизитов уберите `noindex` и добавьте страницы в `sitemap.xml`.

кнопка WhatsApp на мобильных.

## Дизайн-решения

- **Цвет.** Глубина набирается оттенками, а не заливкой: тёмный винный
  (`--wine-950 … --wine-600`), кремовый текст (`--cream`), золото (`--gold`)
  на тонких деталях. Яркий красный (`--accent`) — только основные кнопки,
  бейджи акций и активная точка карусели.
- **Секции чередуются** тёмная / светлая — это и даёт ритм вместо сплошного алого.
- **Иерархия кнопок.** На экране одна залитая CTA; второстепенные действия —
  текстовые со стрелкой. Обводка есть только у кнопки WhatsApp.
- **Типографика.** Manrope (гротеск) + Cormorant Garamond (акцентная антиква),
  системные фолбэки на случай, если Google Fonts недоступны.
- **Mobile-first.** Базовые стили — мобильные, медиазапросы только «вверх»
  (600 / 900 / 1100 px).
- **Анимации** ненавязчивые: появление блоков при скролле, счётчики, ховеры.
  Полностью отключаются при `prefers-reduced-motion`.
- Без JS страница остаётся читаемой (контент виден, цифры на месте).

## Что заменить на реальные данные

Все места помечены в коде комментарием `ЗАМЕНИТЬ`, а в юридических страницах —
подсвечены жёлтым (класс `.fill`).

1. **Телефоны** — `+7 (812) 000-00-00` и три номера салонов (`tel:` тоже).
2. **WhatsApp** — `https://wa.me/78120000000` (4 места: шапка контактов, футер,
   плавающая кнопка).
3. **Адреса, метро, часы работы** — блок `#contacts`.
4. **Тексты услуг, цены и сроки акций** — блоки `#services` и `#promos`.
5. **Отзывы** — тексты, имена, инициалы в аватарах, даты.
6. **Фото команды** — заменить `<div class="ph">…</div>` на
   `<img src="assets/team-1.jpg" alt="Имя, специализация" loading="lazy">`
   (пропорции 3:4, вёрстка не изменится).
7. **Фото в хиро** — блок `.hero__media`, пропорции 4:5.
8. **Соцсети** — ссылки VK / Instagram в футере.
9. **Юридические страницы** — `privacy.html`, `terms.html`, `consent.html`.
10. **Отправка формы** — в JS, обработчик `form.addEventListener('submit', …)`:
    раскомментировать `fetch('/api/lead', …)` и указать свой endpoint или CRM.
11. **Мета-теги** — `og:image` (`assets/og-cover.jpg`), `canonical` и домен,
    если он отличается от `slimcodelab.ru`.
12. **Микроразметка** — блок `application/ld+json` в `<head>`: реквизиты, адреса,
    телефоны, координаты салонов, часы работы, ссылки на соцсети.
    Рейтинг (`aggregateRating`) намеренно не размечен — его допустимо добавлять
    только по реальным подтверждённым отзывам.
13. **Юридические страницы** — реквизиты организации (ИНН, ОГРН, адрес), дата
    редакции, срок хранения данных, название системы аналитики.
    Тексты шаблонные: перед публикацией их должен посмотреть юрист.
    Не забудьте удалить памятку `.notice` в начале каждой страницы.
14. **`robots.txt` и `sitemap.xml`** — домен и дата `lastmod`.

## Проверено

Хром (headless) на 390×844 и 1440×900: горизонтального скролла нет, ошибок в
консоли нет, работают меню, модалка с валидацией, карусель, счётчики, плавающая
кнопка; страница читается с отключённым JS.

Юридические страницы: горизонтального скролла нет, все ссылки оглавления ведут
к существующим разделам, внутренние ссылки между страницами не битые.
JSON-LD разбирается как валидный JSON, `sitemap.xml` — как валидный XML.
