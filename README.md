# Telegram-бот салона красоты

Свой бот вместо конструктора: без абонентской платы, все заявки хранятся у вас.
Написан на Python и работает **на стандартной библиотеке — ничего доустанавливать не нужно**.

Всё, что нужно менять по содержанию (адреса, услуги, цены, акции, тексты), лежит в
обычных текстовых файлах. Код при этом трогать не требуется.

---

## Что умеет бот

**Главное меню — 5 кнопок:** Записаться · Услуги и цены · Акции · Адреса и время работы · Задать вопрос.

- **Запись:** салон → услуга → «когда удобно» (клиент пишет своими словами) → имя → телефон
  (можно нажать кнопку «Отправить мой номер») → подтверждение → заявка уходит администраторам.
- **Услуги и цены:** направления → услуга → карточка с описанием, ценой и длительностью → кнопка записи.
- **Акции:** список предложений, под каждым кнопка записи. В заявке видно, что клиент пришёл по акции.
- **Адреса:** все салоны с часами работы, телефоном и кнопкой-ссылкой на карту.
- **Задать вопрос:** автоответы на частые вопросы + кнопка «Позвать администратора».
  Администратор отвечает прямо из рабочей группы — клиент получает ответ в боте.
- **Кнопка возврата в главное меню — на каждом экране.**
- **Напоминание,** если клиент начал запись и бросил на середине (по умолчанию через 30 минут).
- **Автосообщение через сутки** после заявки: «всё получилось, с вами связались?».
  Если клиент отвечает «нет» — администраторы сразу получают об этом сигнал.

## Быстрый старт

Всё делается один раз, минут за 15.

### 1. Создайте бота в Telegram

Напишите боту **@BotFather** → команда `/newbot` → придумайте имя (например, «Салон Аврора»)
и username латиницей с окончанием `bot` (например, `avrora_salon_bot`).
В ответ придёт **токен** — длинная строка вида `12345678:AAH...`.

⚠️ Токен — это ключ от бота. Не публикуйте его и не пересылайте в переписках.

### 2. Создайте группу для заявок

1. В Telegram создайте группу, например «Заявки — салон».
2. Добавьте туда администраторов салона и **своего бота**.
3. Напишите в группе `/start@имя_вашего_бота` (именно так, с упоминанием бота).

### 3. Заполните config.json

В папке `bot/` скопируйте `config.example.json` в `config.json` и впишите токен:

```bash
cd bot
cp config.example.json config.json
```

Затем узнайте ID группы заявок:

```bash
python3 get_chat_id.py
```

Скрипт покажет список чатов. ID группы начинается с минуса (например, `-1001234567890`) —
впишите его в `config.json` в поле `admin_chat_id`.

### 4. Заполните данные салона

Откройте `bot/salon.json` любым текстовым редактором и замените примеры на свои:
названия и адреса салонов, услуги с ценами, акции, ответы на частые вопросы.

Проверьте, что нигде не потеряли запятую или кавычку:

```bash
python3 check_content.py
```

Скрипт либо скажет «✅ Файл заполнен правильно», либо покажет, в какой строке ошибка.

### 5. Запустите бота

```bash
python3 bot.py
```

В терминале появится «Бот запущен, жду сообщений». Откройте бота в Telegram,
нажмите «Старт» и пройдите запись — заявка должна прийти в вашу группу.

Пока команда работает в терминале — бот живой. Закрыли терминал — бот выключился.
Чтобы он работал круглосуточно, смотрите раздел ниже.

## Как менять содержание

| Что менять | Файл |
|---|---|
| Адреса, часы работы, телефоны, ссылки на карты | `bot/salon.json`, раздел `salons` |
| Услуги, цены, длительность, описания | `bot/salon.json`, раздел `service_categories` |
| Акции | `bot/salon.json`, раздел `promos` |
| Частые вопросы и ответы | `bot/salon.json`, раздел `faq` |
| Тексты сообщений и подписи кнопок | `bot/texts.py` |
| Через сколько напоминать о брошенной записи | `bot/config.json`, `reminder_after_minutes` |
| Через сколько часов писать после заявки | `bot/config.json`, `followup_after_hours` |

Правила, чтобы ничего не сломать:

- В `salon.json` текст всегда в кавычках `"вот так"`, между блоками — запятые.
  После правки запускайте `python3 check_content.py`.
- В `texts.py` не трогайте фигурные скобки: `{salon}`, `{name}`, `{price}` — на их место бот
  подставляет данные. Жирный текст — `<b>текст</b>`, ссылка — `<a href="адрес">текст</a>`.
- После любых правок бота нужно перезапустить (`Ctrl+C`, затем снова `python3 bot.py`;
  на сервере — `sudo systemctl restart salon-bot`).

## Как работают заявки

Заявка приходит в группу карточкой: салон, услуга, пожелание по времени, имя, телефон и ссылка
на клиента в Telegram. Под карточкой кнопка **«Беру в работу»** — нажавший отмечается в сообщении,
чтобы двое администраторов не звонили одному клиенту.

Когда клиент пишет через «Позвать администратора», его вопрос попадает в ту же группу.
Чтобы ответить — **свайпните сообщение бота → «Ответить»** и напишите текст.
Клиент получит его в боте. Отвечать нужно именно ответом на сообщение, иначе бот не поймёт,
кому адресован текст.

Все заявки хранятся в файле `bot/bot.db`. Выгрузить их в таблицу для Excel:

```bash
python3 export_leads.py
```

Появится файл `leads.csv`.

## Круглосуточная работа

На домашнем компьютере бот живёт, только пока открыт терминал. Для постоянной работы нужен
сервер (подойдёт самый дешёвый VPS, 150–300 ₽/мес).

```bash
# на сервере, под пользователем root
mkdir -p /opt/salon-bot
# скопируйте туда содержимое папки bot/ (например, через scp или git clone)

cp /opt/salon-bot/salon-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now salon-bot
systemctl status salon-bot        # проверить, что работает
```

Логи (что происходило с ботом):

```bash
tail -f /var/log/salon-bot.log
```

Бот сам перезапустится после сбоя, перезагрузки сервера или обрыва связи.

## Проверка без Telegram

Прогнать бота по всем веткам, не подключая реальный аккаунт:

```bash
cd bot
python3 selftest.py
```

Скрипт имитирует клиента: запись, вопросы, акции, напоминания, автосообщение через сутки —
и проверяет, что бот отвечает как надо. Полезно запускать после правок в `salon.json` и `texts.py`.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `❌ Telegram не принял токен` | Токен скопирован не целиком или с пробелом. Возьмите его у @BotFather заново. |
| Заявки не приходят в группу | Бот не добавлен в группу, либо в `config.json` неверный `admin_chat_id`. Запустите `python3 get_chat_id.py`. |
| Ответ администратора не доходит до клиента | Нужно отвечать именно «ответом» (свайп → «Ответить») на сообщение бота, а не отдельным сообщением. |
| Бот молчит на кнопки | Он выключен: терминал закрыт или сервер перезагружен. Запустите заново. |
| `❌ salon.json: ошибка формата` | Пропущена запятая или кавычка. В сообщении указан номер строки. |
| Клиент заблокировал бота | Это нормально: бот помечает его и больше не пишет. Заявка остаётся в базе. |

Telegram не даёт боту писать первым тем, кто не нажимал «Старт» — это ограничение самого
Telegram. Поэтому напоминания и автосообщения приходят только тем, кто уже общался с ботом.
